# IA local em 2031 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar documento de tendência validado e deck HTML standalone para discussão do tema 16.

**Architecture:** Um documento Markdown é fonte de verdade das conclusões, com YAML canônico para consumo automático. Um único HTML contém deck, estilos e controlador de navegação, sem build. Um validador Python somente com stdlib testa estrutura do documento e URLs das fontes.

**Tech Stack:** Markdown, YAML validado por Python, Python 3 stdlib, HTML, CSS, JavaScript vanilla, Google Fonts opcionais.

**Spec:** `docs/superpowers/specs/2026-10-06-ia-local-2031-design.md`

## Global Constraints

- Não submeter conteúdo ao site da disciplina sem confirmação explícita do usuário.
- Citar somente URLs verificadas por HTTP 200.
- Tratar APIs de nuvem, self-hosting clássico e quantização INT8/FP16 como contexto maduro.
- Usar exatamente 12 seções canônicas e roda YAML com `roda` e `efeitos` recursivo.
- Cenários de 2031 devem usar pretérito.
- Deck abre como arquivo local, sem build ou bibliotecas JavaScript.
- Não usar em dash em textos gerados do projeto.

## Review Focus

- URL que redireciona ou responde sem 200 deve falhar validação, mesmo que navegador a carregue.
- Título com numeração correta, mas texto diferente, deve falhar validação.
- Efeito sem campos obrigatórios ou sinal fora de `forte`, `medio`, `fraco` deve falhar validação.
- Hash inicial inválido no deck deve abrir primeiro slide sem erro.
- `prefers-reduced-motion` deve desativar transições do deck.
